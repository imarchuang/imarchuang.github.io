Core Idea

A decision path runs from root to leaf

  • Root node is the first split question.
  • Branches represent possible answers.
  • Leaf nodes produce final predicted labels.

Teacher Notes

1 · Mission
Use observable conditions only.

Practice Zone

6 reinforcement exercises + 2 bonus exercises. Completion is saved in this browser.

Reinforcement 1

What is the first question node called?

Hint

Top node.

Answer: Root node.

Why: All paths start from the root.

Reinforcement 2

What does a leaf node represent?

Hint

Path endpoint.

Answer: Final predicted output.

Why: Leaves produce class decisions.

Reinforcement 3

Why choose a high-separation question as root?

Hint

Look at mixed groups.

Answer: It separates samples faster.

Why: It shortens later paths and improves clarity.

Reinforcement 4

Is a deeper tree always better?

Hint

Interpretability and overfitting.

Answer: No.

Why: Very deep trees can overfit and confuse users.

Reinforcement 5

Why must each question be observable?

Hint

Need answer at prediction time.

Answer: Because the model can only use available inputs.

Why: Unobservable conditions cannot be executed.

Reinforcement 6

What is 'rain=yes and wind=strong -> stay inside'?

Hint

Root-to-leaf chain.

Answer: A decision path.

Why: A path links conditions to one output.

Bonus 1

If one root option leaves fewer mixed samples, should it be preferred?

Hint

Think split quality.

Answer: Usually yes.

Why: Better split quality reduces complexity and risk.

Bonus 2

Write a non-anthropomorphic tree explanation.

Hint

Use path and conditions.

Answer: The model checked path conditions and computed the final output.

Why: Keeps explanation testable and precise.
