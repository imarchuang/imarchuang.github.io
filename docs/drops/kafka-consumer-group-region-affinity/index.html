Region 能力不是默认 group 语义

同一 group 默认把订阅了同一 topic 的 member 当成可互换。异构 region consumer 要自己用订阅集合、group 边界、或 custom assignor 把能力表达出来。

不是协议硬拦
Kafka 不会因为 US 进程「不会处理 SG」而拒绝分配。硬限制只有：一个 group 里，一个 partition 同一时刻最多一个 owner。

选择能力边界与故障域

方案 能力匹配 故障域 代价
0 同一 topic + 默认 assignor 不保证。US 实例可能吃到 SG partition。 全体一起 rebalance 零配置，语义错
1 拆 topic，同一 group.id 官方支持。订阅列表就是 capability。 assignment 隔离，rebalance 仍共用 topic 变多；SG 发布会碰 US 一轮 Join/Sync
2 拆 topic，拆 group.id 匹配，且运维隔离 独立 coordinator、独立 rebalance 两套消费应用；offset / 监控按 group 看
3 同 topic + custom assignor partition→region 映射写进 assignor 仍是一个 group 要自己保证每个 region 有兼容实例；新 consumer protocol 不支持客户端 custom assignor
4 所有实例都能处理全部 region 不需要异构。收到记录后走 handler 标准 sticky / static membership 即可 代码必须真的全能；无法按 region 隔离部署能力
