误解侦探

无限循环和错误阈值怎么排查

5 / 7

  • 若变量不更新会导致失败。
  • 阈值过高可能永不达成。
  • 先检查更新语句与停止条件。

快速判断

若 `keys` 初始为 0，循环 3 次每次 +1，`if keys>=3` 结果是？

误区修正

  • 变量不会变化。
    变量值会随程序执行更新。
  • 循环一定自动停。
    循环必须有明确停止条件。
  • if 和 else 会同时执行。
    同一判断只会进入一个分支。

强化练习

强化练习 1

变量 coins 初始 0，4 次每次 +2，最终多少？

提示

累加。

答案: 8。

原因: 状态追踪可快速验证。

强化练习 2

keys=2 时 if keys>=3 走哪个分支？

提示

比较真假。

答案: else 分支。

原因: 条件真假决定分支。

强化练习 3

为什么循环必须有停止条件？

提示

避免无限运行。

答案: 否则可能无限循环。

原因: 终止性是正确性的基础。

强化练习 4

补全：for ... stars = stars + ?（每轮+1）

提示

看增量。

答案: 1。

原因: 循环体决定状态更新。

强化练习 5

变量命名为何要语义化？

提示

考虑协作阅读。

答案: 便于理解与调试，如 keyCount。

原因: 命名影响维护效率。

强化练习 6

if...else 会同时执行吗？

提示

互斥分支。

答案: 不会。

原因: 同次判断只执行一支。

附加挑战

附加挑战 1

写收集 5 枚徽章程序骨架。

提示

初始化->循环->判断。

答案: badge=0; while badge<5: badge++; if badge>=5: 通关。

原因: 完整结构体现状态与终止条件。

附加挑战 2

while 条件依赖变量却不更新，会怎样？

提示

条件值是否变化。

答案: 若初值满足条件会无限循环。

原因: 循环条件相关变量必须更新。
