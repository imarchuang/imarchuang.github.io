按层看：Glean 是知识/工作空间（公司大脑），Codex 是 coding agent（本地开发），Runta 是 execution/runtime（安全执行）。 点产品名看焦点。层和焦点是分类判断，不是各公司官方定位。

层是「产品卖什么」，焦点是「它靠什么赢」。 同一层里的产品仍可能完全不是对手：Glean 和 Granola 都在工作空间，一个卖公司知识大脑，一个卖会议记忆。 Runta 不和 Glean 抢界面，它抢的是 agent 跑起来之后的隔离、密钥和出口。
