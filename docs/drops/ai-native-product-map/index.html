下一阶段不是给旧 SaaS 加聊天框。 System of record → system of action：用户描述目标，AI 读上下文、跨系统执行，人审批结果。 Action 一旦跨系统，价值会重新沉淀到「谁掌握上下文」（Glean）和「谁掌握控制权」（Agent 365 / QM / Managed Agents）。 审批、权限、审计会变成新的 record。
